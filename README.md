CodeAlpha Hangman Game

About

A simple text-based Hangman Game developed using Python for the CodeAlpha Python Programming Internship.

Features

- Random word selection
- Guess one letter at a time
- Maximum of 6 incorrect guesses
- Win and game-over messages

Technology

Python 3

How to Run

Open the VS Code terminal and run:

"py hangman_game.py"

Concepts Used

- Variables and lists
- Loops
- If-else statements
- User input and output
- Random module
